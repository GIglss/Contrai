# SwiftBasicApp

This is a basic Swift iOS application created for testing purposes in Xcode.

## Features
- Simple "Hello, World!" interface
- Uses SwiftUI for the user interface
- Displays a globe icon and welcome text
- Minimal structure for easy testing

## How to Run

1. **Prerequisites**: Make sure you have Xcode installed on a Mac
2. **Open Project**: Open `SwiftBasicApp.xcodeproj` in Xcode
3. **Select Target**: Choose an iOS simulator or connected device
4. **Build and Run**: Press Cmd+R or click the Run button

## Project Structure

```
SwiftBasicApp/
├── SwiftBasicApp.xcodeproj/          # Xcode project file
└── SwiftBasicApp/                    # Source code folder
    ├── SwiftBasicAppApp.swift        # Main app entry point
    ├── ContentView.swift             # Main UI view
    ├── Assets.xcassets/              # App icons and assets
    └── Preview Content/              # Preview assets for SwiftUI
```

## Requirements
- iOS 17.0+
- Xcode 15.0+
- Swift 5.0+

This app is designed to be the most basic possible iOS application to test if you can successfully build and run Swift apps in Xcode.
