# Contrai
Contrai /Conditional Transactions AI Agent/ is an AI agent for smart money management. Create conditional transaction rules (e.g. “Save $100 if balance > $1,000”), get AI-driven financial tips, ask natural questions about your balance or spending, and make transactions using NLP—all in one intelligent, automated finance app.

# Contrai — Conditional Transactions AI Agent

Contrai is an AI-driven finance assistant that lets you:
- Create **conditional transaction rules** (e.g. “Save $100 if balance > $1,000”)
- Ask **natural questions** about your balance and spending
- Receive **AI recommendations** for smarter money management
- Execute **transactions using NLP**
